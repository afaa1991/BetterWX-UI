# 推荐使用某补丁工具

支持平台：Windows x64<br>
支持版本：**4.2.0.9** 附近

## 功能

- 自动登录
- 登录失败也保留登录信息
- 防撤回
- 共存
- 接入系统通知
- 调整时间格式
- 逐条显示时间
- 表情复制为图片
- 不要只读保存
- 防止文件过期
- 使用系统浏览器打开网页
- 关闭内置浏览器
- 无障碍读取控件
- 兼容外部工具
- 关闭托盘闪烁
- 自定义托盘图标
- 自定义提示音

## 用法
[前往发行版](https://github.com/zetaloop/BetterWX/releases)下载并运行 `betterwx`，选择版本启用需要的功能。
